# Анализ эмоциональной окраски текстов с помощью нейросетевых моделей
Учебный проект (аттестационная работа),выполненный в рамках программы профессиональной переподготовки ***«Машинное обучение и искусственный интеллект (для гуманитарных специальностей)»***
## Цель проекта 
Исследовать возможности нейросетевых моделей для определения эмоциональной тональности текста на примере отзывов на гостиницы, опубликованных на Яндекс Картах.
## Задачи
1.Подготовка и обработка текстов отзывов.

2.Анализ частоты слов в отзывах в зависимости от рейтинга, выявление слов, специфичных для отзывов с высоким и низким рейтингом.

3.Использование предобученной нейросетевой модели для определения эмоциональной тональности отзывов и анализ полученных результатов.
## Данные
Датасет отзывов на гостиницы, опубликованных на Яндекс Картах.
## Инструменты и модель
**Pandas** — обработка и анализ данных

**Matplotlib, Seaborn** — визуализация данных

**WordCloud** — визуализация в виде облака слов

**NLTK** — токенизация и стоп-слова

**Pymorphy2** — морфологический разбор (лемматизация) русского текста

**Transformers (Hugging Face), PyTorch** — загрузка и применение предобученной модели

**Plotly** — интерактивная визуализация

**Модель**: ruBERT-base-cased-sentiment — предобученная модель на основе архитектуры BERT для анализа тональности русскоязычного текста (классы: positive / negative / neutral)
